Not in this demo — the public site and its "Live Demo" tab query a small illustrative dataset so anyone can try it without touching a real system. The officer panel is architected against the same schema a real registry/blacklist connector would use, so wiring in an actual government feed is a connector swap, not a redesign.

Image forensics and MRZ checksum validation run entirely client-side, so they still work offline.
